# Componentes de terceros

Trazo integra el editor de Excalidraw y las siguientes dependencias principales. Sus avisos originales se conservan en los paquetes instalados.

- Excalidraw `0.18.0-2c3dcc0`: MIT. [Aviso conservado](public/licenses/LICENSE) · [repositorio](https://github.com/excalidraw/excalidraw).
- Mermaid to Excalidraw `3.6.0`: MIT. [Repositorio](https://github.com/excalidraw/mermaid-to-excalidraw).
- React y React DOM `19.3.1`: MIT. [Repositorio](https://github.com/facebook/react).
- Headless UI `2.2.10`: MIT. [Repositorio](https://github.com/tailwindlabs/headlessui).
- Lucide React `1.77.0`: ISC. [Repositorio](https://github.com/lucide-icons/lucide).
- Tailwind CSS `4.3.5`: MIT. [Repositorio](https://github.com/tailwindlabs/tailwindcss).

Las fuentes se copian sin modificar desde el paquete publicado de Excalidraw.
